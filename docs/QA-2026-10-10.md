## Périmètre et conclusion

Les **68 critères A01–A68 de [PROJET.md](../PROJET.md#14-scénarios-dacceptation) sont recensés ci-dessous**, chacun avec les preuves disponibles et les limites. Ce recensement ne signifie pas que les 68 critères ont tous été rejoués intégralement dans le navigateur ou sur du matériel.

La validation porte sur le **checkout local non publié**, basé sur `05919d6`, avec les modifications présentes le 10 octobre 2026. Le manifeste porte encore `0.1.1` ; cela ne rattache pas les changements non publiés à la release GitHub `v0.1.1` existante.

- Home Assistant **2026.10.0**, frontend officiel **20260930.2**, Python **3.14**, Node **24**.
- Instance de recette sur **127.0.0.1:18123** uniquement, distincte de l’instance domestique.
- Présence `binary_sensor.qa_presence`, luminosité `sensor.qa_lux`, soleil `sun.qa_sun`, auxiliaires et états injectés de manière contrôlée.
- Quatre lampes simulées dans Atelier QA (effets/HS/température, RGBW, RGBWW, blanc), une lampe extérieure et une scène native enregistrée. Les compteurs et événements de service permettent de vérifier les commandes, leurs paramètres et l’absence de répétition.
- Les tests Python utilisent le moteur, le stockage, les entités et les API Home Assistant ; les périphériques restent simulés. Les tests frontend utilisent Lit/Happy DOM ; ils ne rendent pas le CSS comme un navigateur.

**Résultats acquis : 464 tests Python réussis, 87 tests frontend réussis et 15 scénarios de services dans Home Assistant isolé réussis.** Les contrôles TypeScript, Ruff et Hassfest local passent. Le bundle final a été reconstruit deux fois à l’identique et chargé dans l’instance isolée. Les parcours graphiques ont été observés en clair à 768 et 1 440 pixels et en sombre à 375 pixels ; leur portée précise figure dans la matrice.

Il n’y a **ni release, ni installation HACS, ni déploiement domestique** dans cette recette. L’autorisation d’une mise en production n’est pas déduite de ces résultats.
