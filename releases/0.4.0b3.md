## Spanish support — beta

**0.4.0b3 is a prerelease.** The latest stable release remains **0.3.1**. To include betas in HACS update checks, enable Halo’s HACS prerelease switch entity if disabled, then turn it on. See the [HACS switch documentation](https://www.hacs.dev/docs/use/entities/switch/).

This beta adds complete Spanish translations alongside English and French:

- All 335 panel texts, including help, errors, entity search, scene editing, natural light profiles and accessible control labels.
- Home Assistant setup, entity names and fixed status values, including **Control directo** and **Luz nocturna**.
- Activity messages describing requested commands and their reasons, while preserving custom scene names.

The panel follows each user’s Home Assistant interface language and recognizes `es` and regional variants such as `es-ES` and `es-MX`. Activity messages follow the server language at the time of the command; existing history is unchanged. Unsupported languages and missing panel translations fall back to English. Switching language preserves custom names, entity identifiers, selections and unsaved drafts.

The visual profile editor and smooth daytime/nighttime joins from 0.4.0b2 remain included. Compared with 0.4.0b2, this release changes localization and documentation; lighting rules, APIs and dependencies are unchanged. There is no configuration migration.

### Compatibility and validation

Requires **Home Assistant 2026.10.0 or newer**. The compiled panel is included; installation does not require a frontend build.

Frozen dependency synchronization, Ruff, formatting and **581 Python tests** pass. Under **Node.js 24.21.0**, `npm ci`, TypeScript, **127 frontend tests** and two identical builds pass. Bundle SHA-256: `3356199b7931d035fcf5e181aa67c34aeac3c71e460c3d97365e478151ffae10`. Checks cover complete catalogs and placeholders, locale variants, native entity translations, Activity requests and custom scene names, accessible profile labels, and saving a draft after changing language.

The simulated panel was checked in Chrome at **1440 × 1100** in light mode and **390 × 844** in dark mode, in Spanish, without horizontal overflow, JavaScript errors or light commands. These checks do not constitute household hardware validation or a new test in the isolated Home Assistant instance. Publication is gated by the release workflow’s metadata, Python, panel reproducibility, Hassfest and HACS checks. No Home Assistant installation or restart is part of this release.
