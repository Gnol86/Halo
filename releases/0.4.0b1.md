## Visual natural light profiles — beta

**0.4.0b1 is a prerelease for testing the new visual profile editor.** The latest stable release remains **0.3.1**. To include beta versions in HACS update checks, enable the repository's HACS prerelease switch entity if it is disabled, then turn it on. See the [HACS switch documentation](https://www.hacs.dev/docs/use/entities/switch/). Stable users do not need to opt in.

The profile editor replaces the two separate charts and their main forms with one interactive schematic day:

- A dashed sun path runs from night through sunrise, highest sun and sunset to the next night. A brightness curve uses a 0–100% scale, with its fill showing white temperature.
- Separate rows of handles adjust the brightness and temperature elevations at the start and end of morning and evening. Select an endpoint to adjust its brightness and logarithmic temperature sliders; each slider shows its own sun elevation.
- Morning and evening remain visible together. Unlinking creates independent settings; linking again uses the morning settings for both periods, as explained beside the control.
- Exact numerical values and linear or gradual progression remain available in collapsed **Advanced settings**. Existing shared drafts, saving, discarding, validation and conflict handling are retained.

The editor supports mouse dragging, touch and keyboard controls, with 44 px touch targets and complete English/French labels. The chart is based on sun elevation, without clock times or geographic calculations. Its color fill is an indicative preview, not a calibration of physical lamps.

## Compatibility

Requires **Home Assistant 2026.10.0 or newer**. There is **no configuration migration**: existing profile values and structures remain compatible. The Python lighting engine, APIs and dependencies are unchanged. Adjusting the preview modifies only the configuration draft and sends no light commands or live-editing requests.

This release contains the compiled panel. Installing it does not require a frontend build. Publication is separate from downloading, installing or restarting Home Assistant.
