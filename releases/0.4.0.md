## Visual profiles, smoother natural lighting and Spanish

**0.4.0 is a stable release.** It brings the visual profile editor, smoother natural lighting and Spanish translations to the standard release. This promotion keeps the application code and compiled panel from 0.4.0b3; only version metadata, release notes and documentation change.

### Visual profile editing

- Adjust a whole schematic day on one chart, with a dashed sun path, a brightness curve and an opaque fill showing white temperature.
- Move brightness and temperature handles independently for the start and end of morning and evening. Keep both periods linked or configure them separately.
- Use whole percentages and kelvins, color guides and a logarithmic temperature slider. Sun handles adjust to hundredths of a degree; exact values and progression types remain available in Advanced settings.
- New profiles use gradual curves. Existing profiles retain their values and progression types. Shared drafts, saving, discarding and validation keep their existing behavior.

The editor supports mouse, touch and keyboard controls. Its preview changes only the draft and sends no light commands or live-editing requests.

### Smoother natural lighting

Unlinked morning and evening curves connect smoothly through both daytime and nighttime in the preview and lighting engine. With valid solar-event metadata, the engine uses real solar timing, attainable elevations and precise Astral elevation to avoid jumps near noon and midnight from rounded or stale sun states.

Custom sun sources without valid `next_noon` and `next_midnight` metadata use a schematic fallback that does not guarantee alignment with real solar noon. The editor is always a schematic preview, without clock times or geographic calculations.

### Spanish support

Spanish joins English and French across all 335 panel texts, setup, entity names, fixed states and Activity messages. The panel follows each user's Home Assistant interface language, including regional variants such as `es-ES` and `es-MX`. Activity follows the server language when a command is recorded. Unsupported languages fall back to English.

Custom room, profile and scene names, entity identifiers, selections and unsaved drafts are preserved when switching language. Existing Activity history is unchanged.

### Compatibility and validation

Requires **Home Assistant 2026.10.0 or newer**. Existing configurations and APIs remain compatible without migration. The compiled panel is included. After updating, restart Home Assistant and reload the browser to load the new version.

The unchanged 0.4.0b3 sources passed **581 Python tests**, **127 frontend tests**, Ruff, TypeScript and reproducible builds under Node.js 24.21.0. The stable release workflow reruns Python, frontend, bundle reproducibility, metadata, Hassfest and HACS checks before publication.
