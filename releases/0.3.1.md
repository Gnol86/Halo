## HACS catalog installation and README buttons

Halo was accepted into the default HACS catalog on October 21, 2026. The English and French installation guides now start with searching for **Halo** directly in HACS. Custom repository instructions remain available as a fallback while the catalog update propagates.

Both READMEs include My Home Assistant buttons to open Halo in HACS and start adding the integration after download and restart. They also include a Buy Me a Coffee support button.

This is a documentation release. HACS reads repository documentation from the published or installed version, so this release makes the updated README available with the new version. The lighting engine, panel bundle, settings and dependencies are unchanged from 0.3.0; only the integration version metadata changes in the installed package.

## Validation and compatibility

The README links, button parameters, image availability and English/French consistency have been checked. Version metadata is aligned in the manifest, project metadata and lockfile. Publication requires the release workflow's metadata, Python, panel, Hassfest and HACS checks to pass.

Requires **Home Assistant 2026.10.0 or newer**. There is no new configuration migration. Publishing this release does not install it or restart Home Assistant; household availability and installation remain separate checks.
