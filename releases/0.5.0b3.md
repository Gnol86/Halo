## Reliable presence lighting — beta

**0.5.0b3 is a prerelease. The latest stable release remains 0.4.0.**

After an absence, a Hue group can still report a light as on. Halo previously treated the next arrival as a gradual natural-light adjustment, so a short passage could remain much too dim even when the profile requested adequate brightness.

- A genuine return after the configured absence delay restores the applicable base ambience, natural profile or presence-dependent scene using the configured **turn-on transition**, including zero or no explicit transition. It restores the full ambience even when a light still reports on.
- Normal lighting permission remains required. This does not extend the separate short-return exception for stale illuminance readings, and does not override manual holds, live editing or disabled automation. Brief absences and presence attribute updates do not recall the ambience; autonomous scenes keep their existing priority.
- If a light still reports on after an accepted off command, normal policy evaluations can retry extinction after the requested fade plus a short feedback grace period. Lamp reports do not immediately issue commands, and a running fade is not repeatedly restarted.
- A newer explicit command supersedes presence evaluations already waiting for a slow service, preventing an intermediate automatic flash before a manual off command.

Existing profiles, brightness levels, transition durations and configuration are preserved. No migration, dependency or panel change is required. Requires **Home Assistant 2026.10.0 or newer**; the compiled panel is included.

### Validation

Local validation passes **715 Python tests** (including 20 new regression cases), **140 frontend tests**, frozen dependency synchronization, Ruff, formatting and TypeScript. The rebuilt panel is byte-for-byte unchanged. Independent review found no remaining blocking issue in this scope.

Regression tests replay the observed hall configuration and delayed group feedback through simulated Home Assistant states and light services. They cover the requested brightness and transition, extinction retries, context-free reports, long fades and command ordering. These tests do not establish the origin of the historical Hue feedback or validate physical lamp behavior.

Publication is gated by metadata, Python, panel reproducibility, Hassfest and HACS checks. No Home Assistant installation, update or restart is part of this release.
