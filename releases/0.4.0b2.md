## Smoother natural light profiles — beta

**0.4.0b2 is a prerelease.** The latest stable release remains **0.3.1**. To include betas in HACS update checks, enable Halo’s HACS prerelease switch entity if disabled, then turn it on. See the [HACS switch documentation](https://www.hacs.dev/docs/use/entities/switch/).

### Profile editing

- Brightness sliders use whole percentages and temperature sliders use whole kelvins, while retaining the logarithmic temperature scale. Solar handles adjust to hundredths of a degree; arrow keys move by 1° or 0.01° with Shift.
- Color guides above both sliders show the selected light range. The chart fill is opaque in light and dark themes, and the solar position marker stays circular as the graph resizes.
- New profiles, including the initial profile of a fresh installation, use gradual curves. Existing profiles retain their values and progression types; exact decimals remain available in Advanced settings.
- Unlinked morning and evening curves now connect smoothly through both daytime and nighttime, in the preview and the lighting engine.

### Continuous lighting

The engine uses real solar timing and attainable elevations when the sun source exposes valid solar-event metadata. It handles unreachable thresholds and uses precise Astral elevation to avoid discontinuities caused by rounded or stale native sun states near noon and midnight. Linked profiles retain their behavior.

Custom sun sources without valid `next_noon` and `next_midnight` metadata fall back to a schematic cycle based on elevation and rising/setting. This fallback does not guarantee alignment with that source’s real solar noon. The visual editor remains a schematic preview without clock times or geographical calculations.

### Documentation and compatibility

The six README illustrations show only the Halo panel, with simulated devices and fully localized English/French demo names. Their simulated origin is disclosed in the accompanying README text, without test controls or banners in the images. Real custom room, scene and profile names remain unchanged. The README also includes the community discussion and repository badges.

Requires **Home Assistant 2026.10.0 or newer**. There is **no profile migration or API change**. Unlike 0.4.0b1, this beta updates the Python lighting calculation as well as the panel. Adjusting the chart changes only the draft and sends no light commands or live-editing requests. The compiled panel is included; installation does not require a frontend build.
