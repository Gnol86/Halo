## Home Assistant sidebar access — beta

**0.5.0b2 is a prerelease. The latest stable release remains 0.4.0.**

On small screens, Home Assistant hides its sidebar and Halo previously offered no button to reopen it. This beta adds a hamburger menu button before the Halo lotus in the header.

- Opens the Home Assistant sidebar while preserving the current Halo view and unsaved settings.
- Appears when Home Assistant reports a narrow screen or the sidebar is hidden in the user's preferences. It follows the host's kiosk and external-app sidebar exclusions.
- Uses the active Home Assistant theme, a 48 × 48 px target, visible keyboard focus and accessible labels in English, French and Spanish.
- Sends only the host menu-opening event: no light command, configuration save or change to the lighting engine.

The optional identified manual-command detection introduced in 0.5.0b1 is unchanged: **disabled by default**, with a default pause duration of **120 minutes**, preserving explicitly configured durations. No configuration migration or dependency change is introduced by this update. Requires **Home Assistant 2026.10.0 or newer**; the compiled panel is included.

### Validation

Local validation passes **695 Python tests** and **140 frontend tests**, frozen dependency synchronization, Ruff, formatting and TypeScript. Two builds under Node.js **24.21.0** produce the same panel SHA-256: `14263da97a93369b371d3ea8d5a34d3a97c66177f4315b704aa48c4bdf21b6e0`.

Regression tests cover the host layout and preferences, translations, event propagation through shadow roots, and draft preservation without extra API calls. Simulated Chrome checks cover 390, 840 and 1440 px layouts, light/dark themes, mouse and keyboard interaction, with no observed JavaScript errors or global horizontal overflow. A separate native check in an existing local Home Assistant instance confirmed that clicking the button opens its drawer; the new bundle was supplied only to an isolated browser without installing it or changing Home Assistant configuration. These navigation checks do not validate household hardware behavior.

Publication is gated by metadata, Python, panel reproducibility, Hassfest and HACS checks. No Home Assistant installation, update or restart is part of this release.
