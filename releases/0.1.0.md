## First Halo release

Halo centralizes lighting control in a single Home Assistant sidebar panel.

- Room devices with a room light, automatic and natural-light switches, resume button and lighting-status sensor.
- Presence and brightness automation, manual pauses and configurable transitions.
- Shared natural-light profiles with linear or smooth S-curves, separate morning/evening settings and per-room associations.
- Prioritized scenes, live editing through Home Assistant's native light controls, effects and filtered imports from existing Home Assistant scenes.
- Compact dashboard following the Home Assistant theme, with English and French translations.
- Protection against brief presence dropouts: fast relighting after absence and preservation of manual mode on short absences.

## Installation and updates

Requires **Home Assistant 2026.10.0 or newer**. Add `Gnol86/Halo` as a custom **Integration** repository in HACS and select this release. For a manual installation, copy `custom_components/halo` from the source archive into your Home Assistant configuration and restart Home Assistant.

The compiled panel, translations and lotus images are included. Existing settings are preserved; configurations without the new presence-protection setting receive its 30-second default.

## Development status

This is an early development release. Automated tests use simulated lamps and sensors; targeted UI checks have been performed in an isolated Home Assistant instance. Complete validation on household equipment is still pending, particularly transitions and manual-change detection on devices that do not preserve command context.

Halo is distributed as a HACS custom repository. Inclusion in the default HACS catalog has not been requested. Publishing this release does not install or activate it in your Home Assistant instance.
