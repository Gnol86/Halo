## Dashboard refinements

- Entity pickers no longer repeat the selected entity or display an unnecessary "No entity" line below the field. Search, keyboard navigation, validation and availability information remain available.
- Fields on the same row stay aligned when their labels wrap onto different numbers of lines, including the room's presence settings.
- The "Changes saved." confirmation disappears after four seconds. Another successful save restarts the delay; errors and warnings are not dismissed by this timer.

## Installation and updates

Requires **Home Assistant 2026.10.0 or newer**, unchanged from 0.1.0. Update Halo through its custom **Integration** repository in HACS, then restart Home Assistant and reload the browser to load the updated panel. For a manual installation, replace `custom_components/halo` with the folder from this release's source archive before restarting.

The compiled panel is included. Existing configuration is preserved; no new configuration or separate frontend installation is required.

## Validation and development status

Validation for these changes uses local automated checks and browser previews with simulated data. These checks do not establish behavior on household equipment or confirm installation in a domestic Home Assistant instance.

Halo remains an early development integration distributed through a HACS custom repository. This release does not add Halo to the default HACS catalog or install it automatically.
